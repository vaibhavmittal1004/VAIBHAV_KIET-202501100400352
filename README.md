# SAIR.life – Travel Inspiration Website  

SAIR.life is a simple yet visually engaging **HTML-based travel inspiration website** that encourages exploration, adventure, and cultural discovery. It combines travel quotes, destination highlights, activity showcases, essential travel information, and package details, creating a complete travel-themed experience for visitors.  

This project has been designed using only **HTML5**, without any external frameworks or libraries, making it a lightweight and beginner-friendly travel webpage.  

---

## Technical Details  

- **Technologies used:** Pure HTML5 (No CSS, No JavaScript).  
- **Tags demonstrated:**  
  - Structural Tags: `<h1>, <h2>, <p>, <hr>, <br>`  
  - Lists: `<ol>, <ul>, <dl>`  
  - Media: `<img>` with `alt` and `height` attributes  
  - Links: `<a>` with internal and external references  
  - Tables: `<table>, <thead>, <tbody>, <th>, <tr>, <td>`  
- **Formatting Tags:** `<strong>, <i>, <u>` used for emphasis.
